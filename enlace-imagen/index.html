🔗 Crea tu enlace con imagen o video

Selecciona una imagen o video desde tu teléfono, o pega la URL de un archivo alojado.

La herramienta crea un archivo HTML descargable que incluye tu imagen o video. Para obtener un enlace web permanente, debes alojar ese archivo HTML en un servidor. Facebook tampoco garantiza vistas previas clicables de publicaciones normales.
